## Why Care?

JSR's score is what someone sees next to the package name before deciding to
use it, and the score is mostly about whether the API explains itself.

## What's New?

- Module docs on `/formats`, `/formats/yang`, `/formats/json-schema`,
  `/formats/plantuml` and `/resolve-path`.
- JSDoc on the 55 exported symbols that had none.
- `.github/workflows/publish-jsr.yml` publishes to JSR when a `v*` tag is
  pushed, which gives each version provenance.

## Under the Hood

JSR's score for 0.9.0 came from four checks it didn't pass:

| Check | Fix |
|---|---|
| Entry points without module docs | `@module` on the five headers that lacked it |
| 88% of symbols documented | JSDoc on every symbol `deno doc --lint` flagged |
| Provenance | Publish from GitHub Actions with an OIDC token |
| Package description | Set on jsr.io; `deno.json`'s `description` isn't read |

Provenance also needs the GitHub repo linked in the package's settings on
jsr.io, or the CI publish is refused.
