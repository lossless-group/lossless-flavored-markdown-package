## Why Care?

JSR shows a package's README and nothing else. After the README was shortened, the next release would have left JSR readers with a table of links out to GitHub. Now the guides come with the package page, and their links jump to the right heading on that page.

## What Changed

- **`pnpm lfm:jsr`** publishes the README with every guide in `docs-v/index.md` added, then restores the short one.
- **A new test** fails if a guide goes missing from that page or one of its in-page links stops landing on a heading.
- **The publish script** now does the check for uncommitted changes itself, because swapping the README needs `--allow-dirty`.

This reaches JSR with the next release, because published versions can't change.
