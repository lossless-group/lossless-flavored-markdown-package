## Why Care?

LFM's guides lived as markdown files in `docs-v/`, readable on GitHub and
appended to the JSR page. That works when you know where to look. Now they're a
proper documentation site: every guide is a page, there's a sidebar grouped by
what you can write, a table of contents for each page, search, and light and
dark modes.

[LFM docs](https://lossless-group.github.io/lossless-flavored-markdown-package/docs/)

## What's New?

- **A docs site at `/docs/`** on the LFM site, linked from the header and from
  the README.
- **Getting started is the README,** then every guide: headings, citations,
  cross-reference embeds, MDX, wikilinks, link previews, image carousels, code
  fences, highlighting and tasks, plus the types reference and the roadmap.
- **Search** across all of it.

## Under the Hood

- Built with Starlight in `user-docs/`, reading `docs-v/` and the README where
  they are. There's still one copy of each guide, and the GitHub and JSR
  versions keep working.
- Links between guides stay written as `headings.md`, which works on GitHub; a
  small remark plugin turns them into site links when the site builds.
- It's a separate Astro project because Starlight needs Astro 7 and brings its
  own search index; the splash is on Astro 6 with its own. The Pages workflow
  builds both and publishes the docs inside the splash at `/docs/`.
- The README's mermaid diagram shows as code on the docs site for now.
